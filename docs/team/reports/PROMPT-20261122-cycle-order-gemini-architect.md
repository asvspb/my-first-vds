## 1. Что спрашивается (узко)

Не «что делать» (владелец уже выбрал пул кандидатов), а:

1. **Последовательность.** A → B → C или иначе? Оверлапы:
   - B (новый AWG-бинарь) меняет то же, чем управляет C (порт/поток AWG) и
     что мерит P25-манёвр (liveness awg1);
   - A (XHTTP-конфиг) не касается AWG-контура, но приёмка probe/silence
     должна идти в окно без других изменений вариативности (урок soak 21.11);
   - guard v1.1 (post-G6, уже скоуплен в TECHDEBT P19✅/P21✅/P27) и
     `--enable-auto` — в какую точку последовательности их встраивать.
2. **Окна.** Какое окно требуется каждому (спокойное = без других
   изменений; живая приёмка asv2/релей/клиенты).
3. **WP-разбиение + критерии приёмки** для каждого кандидата (текстом,
   без кода).
4. **Риски/откаты** по каждому, особенно B: совместимость AWG 1.5
   (relay LandVPS ↔ exit asv2 ↔ Android/Windows клиенты), откат бинаря.
