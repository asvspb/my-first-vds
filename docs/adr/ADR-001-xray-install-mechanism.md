# ADR-001: Механизм установки Xray-core

- **Дата:** 2026-11-07
- **Статус:** accepted
- **Контекст SPEC:** [SPEC-20261107-gateway-mvp](../team/specs/SPEC-20261107-gateway-mvp.md)

## Контекст

Нужен воспроизводимый, верифицируемый и идемпотентный способ поставить бинарь
Xray-core на Ubuntu 24.04 (OQ-3 из REQ). Классический путь — официальный
`install.sh` с `github.com/XTLS/Xray-install` — ставит «последний release» и
системные юниты `xray.service`, которыми мы не хотим управлять (наши юниты —
только из шаблонов `systemd/`, см. AGENTS.md §6).

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| A. Официальный install-скрипт Xray-install | поддерживается апстримом, ставит geodata | непининовая версия; чужие systemd-юниты; сложно проверить контрольную сумму; тяжело сделать идемпотентным с нашим store |
| B. Direct download release с GitHub: пин версии + SHA256 из `.dgst`-ассетов | версия зафиксирована; контрольная сумма от апстрима; ставим только бинарь+geodata; наш юнит из шаблона; тривиальная идемпотентность | свой код загрузки/распаковки; зависимость от доступности GitHub с VDS |
| C. Пакет из дистрибутива (apt) | простота | в Ubuntu 24.04 нет актуального Xray; версия древняя, без XHTTP/актуального Reality |

## Решение

**Вариант B.** Версия Xray-core пинится константой в `src/xray/install.py`
(`XRAY_VERSION`, формат `vX.Y.Z`, обновляется только коммитом). Загрузка
`Xray-linux-64.zip` из release-ассетов; SHA256 сверяется со значением из
ассета `Xray-linux-64.zip.dgst` (подписанный апстримом дайджест). Установка:
`/usr/local/bin/xray` + `/usr/local/share/xray/geodata.dat, geoip.dat`;
systemd-юнит — только из нашего шаблона `systemd/vds-xray.service.tpl`.
Если версия уже установлена (`xray version` совпадает и файл на месте) —
повторный install не перекачивает (идемпотентность, E4/E6).

## Последствия

- Положительные: детерминированная версия, верифицируемость, наш контроль
  юнитов, простая идемпотентность.
- Отрицательные / долг: при недоступности GitHub с VDS установка падает —
  задокументировать; mirror/прокси — вне MVP.
- Трудно изменить позже: структура путей — но она локализована в `install.py`.

## Как откатить

`vds xray remove --apply` удаляет бинарь, geodata, конфиг и юнит (см. SPEC §5).
ADR обратим заменой механизма в `install.py` без изменения интерфейса адаптера.
