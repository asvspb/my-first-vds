# ADR-017 — Сменяемый exit / multi-exit failover на RU-реле (DRAFT — не принят)

> **Статус:** DRAFT-плейсхолдер (DECISION Q4-PRI 2026-11-24). Решений в этом
> документе пока нет; скоуп и обоснование — TECHDEBT.md **P38**. Утверждение
> (G2) — только после Фазы 1: ручная DR-репетиция asv2→ES-1 (≤ 15 мин, без
> нового кода). Клиентский Smart Failover v2.0 → ADR-018+ (формулировка
> ADR-016 «ADR-017+»).

**Контекст (черновой):** ADR-016 описывает смену L4-носителя к одному exit
(egress-IP не меняется). Переключение между разными exit меняет внешний IP
всех клиентов за релеем: рвутся stateful-сессии, требуются новые /30-подсети
(10.13.x/10.14.x), формат exits[] в `/var/lib/vds/p2p-carriers.json`, единый
lock с P25, антифлаппинг (switch на exit-B только после отказа ОБОИХ носителей
exit-A; возврат — ручной или cooldown ≥ 60 мин), новая модель алертов.
